# Day 3 - Terraform Import: Managing Existing Infrastructure

## Concepts Covered
- Using `terraform import` to bring existing GCP resources under Terraform management
- Importing a pre-existing VPC network (`clickops-vpc`)
- Importing a pre-existing compute instance (`clickops-ubuntu-vm`)
- Reviewing and refactoring generated configuration

## Usage

```bash
cp terraform.tfvars.example terraform.tfvars
# Edit terraform.tfvars with your GCP project ID
terraform init
terraform plan
```

> Note: The resources in `main.tf` were generated by `terraform import`. The project ID in resource attributes should match `var.gcp_project_id`.
