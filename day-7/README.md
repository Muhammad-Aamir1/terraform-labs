# Day 7 - `for` Expressions and Map Filtering

## Concepts Covered
- `for` expression to filter maps conditionally
- Filtering users by department (`engineering`)
- Creating IAM service accounts only for filtered users
- `for_each` with filtered maps

## Usage

```bash
cp terraform.tfvars.example terraform.tfvars
# Edit terraform.tfvars with your GCP project ID
terraform init
terraform plan
terraform apply
```
